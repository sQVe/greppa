# greppa

Grasp your code changes. Local-first code review that scales.

greppa is a native desktop app for reviewing code changes on your own machine. It reads diffs from
the Git repository on disk, so large changes and changes that are not pull requests yet get a full
review. It is written in Rust on [GPUI](https://www.gpui.rs).

greppa is in early development.

See [the documentation](docs/README.md) for the development guide and architecture decisions.
